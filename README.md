# Abyss Spells

An addon for [Iron's Spells 'n Spellbooks](https://modrinth.com/mod/irons-spells-n-spellbooks) (Minecraft 1.21.1, NeoForge) adding the **Abyss school**: 10 spells, a wizard set, staff, focus item and custom entities.

## Content

- **Spells**: Abyssal Crush, Void Claim, Blood Price, Equilibrium, Delayed Doom, Abyss Core, Offering, Transposition, Retribution, Fate Anchor
- **Gear**: Abyss wizard set, Abyss Staff, Abyss Heart focus, Affinity Ring support
- **Entities**: Void Shackles, Abyss Core, Fate Anchor marker

## Build

Requires JDK 21. Uses the Gradle wrapper, no manual Gradle install needed:

```bat
set JAVA_HOME=D:\GenshinPrivateServ\JDK21
gradlew.bat build
```

The jar lands in `build/libs/`.
